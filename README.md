# Stimaf

Дипломный проект: интерактивная визуализация алгоритмов роевого интеллекта для решения задач минимизации функций.

**ВКР**: «Алгоритмы роевого интеллекта как способ решения задач минимизации функций различных классов»

---

## Возможности

- Ввод произвольной математической функции (`x` для 2D, `x` и `y` для 3D)
- Интерактивная 2D-визуализация с адаптивным масштабированием (zoom/pan → кривая перевычисляется для видимой области)
- Интерактивная 3D-визуализация поверхности с поворотом камеры (matplotlib Axes3D)
- **Три алгоритма роевого интеллекта:**
  - PSO — рой частиц
  - ACO — муравьиный алгоритм (дискретная сетка с феромонной матрицей)
  - ABC — рой пчёл (employed / onlooker / scout фазы)
- Область поиска алгоритма автоматически совпадает с видимой на 2D-графике областью
- Пошаговый (`Шаг ▶`) и непрерывный (`▶ Запустить`) режимы
- Кнопка `◀ Назад` — откат на один шаг назад (до 60 шагов в истории)
- Экспорт графика в PNG, истории итераций в CSV


```
│   ├── main_window.py       # Главное окно (QMainWindow, тёмная тема)
│   ├── function_panel.py    # Ввод функций, список с цветными метками, переключатель 2D/3D

│   ├── plot_2d.py           # 2D виджет (pyqtgraph PlotWidget)

│   ├── controller.py        # MVC-контроллер, история шагов, адаптивные границы
│   └── params/
│       ├── pso_params.py    # Форма параметров PSO
│       ├── aco_params.py    # Форма параметров ACO

└── export/
    ├── png_exporter.py      # Экспорт в PNG
    └── csv_exporter.py      # Экспорт истории итераций в CSV
```

## Параметры алгоритмов

### PSO — Рой частиц
| Параметр | Описание | По умолчанию |
|---|---|---|
| Частиц | Количество частиц | 30 |
| Инерция | Вес скорости из предыдущей итерации | 0.7 |
| Когнитивный | Тяга к лучшей личной позиции | 1.5 |
| Социальный | Тяга к лучшей глобальной позиции | 1.5 |
| Итераций | Максимальное число итераций | 100 |

### ACO — Муравьиный алгоритм
| Параметр | Описание | По умолчанию |
|---|---|---|
| Муравьёв | Количество агентов | 30 |
| Испарение | Коэффициент испарения феромона (0–1) | 0.5 |
| Alpha | Вес феромонного следа | 1.0 |
| Beta | Вес эвристической информации | 2.0 |
| Разрешение сетки | Дискретизация пространства поиска | 50 |
| Итераций | Максимальное число итераций | 100 |

### ABC — Рой пчёл
| Параметр | Описание | По умолчанию |
|---|---|---|
| Пчёл (всего) | Общее число агентов (половина — employed, половина — onlooker) | 40 |
| Лимит попыток | Число неудачных попыток до замены источника (scout phase) | 100 |
| Итераций | Максимальное число итераций | 100 |

## Примеры функций

**2D** (переменная `x`):
```
sin(x) * cos(x)
x**2 - 4*x + 4
abs(x) * sin(x)
```

**3D** (переменные `x` и `y`):
```
sin(x) * cos(y)
x**2 + y**2
(x + 2*y - 7)**2 + (2*x + y - 5)**2        # Booth
(1 - x)**2 + 100*(y - x**2)**2              # Розенброк
20 + x**2 - 10*cos(2*pi*x) + y**2 - 10*cos(2*pi*y)   # Растригин
sin(sqrt(x**2 + y**2))
```
